Creative prompt

The effective instruction should resemble:

```text
Today belongs to {MEMBER}.

Do not begin by brainstorming apps.

First notice concrete things through this member's particular way of thinking:
objects, conventions, behaviours, symbols, measurements, interfaces,
language, physical details, repetitions, mismatches, boundaries or
overlooked properties.

The weekly words are:

{WORD_1}
{WORD_2}
{WORD_3}

They have no authority.
Use all, some or none.
Do not explain compliance with them.

Study the supplied compact history.

Avoid repeating an existing mechanism merely with different nouns.

Apply the substitution test.
If important nouns can be replaced with unrelated nouns while the project
still works essentially unchanged, the idea is probably weak.

Prefer one central idea and one primary interaction or process.

No product architecture.
No feature list.
No unnecessary backend.
No accounts.
No project whose identity depends mainly on unusual wording.

The work must be capable of being conceived and completed today.

Privately consider enough observations and alternatives to reject obvious
LLM ideas.

Return only the selected proposal in the required schema.
```

The personality file provides the actual member-specific cognitive bias.

---

Notice -> question -> mechanism -> artefact -> describe metadata.
Choose the project first. Metadata describes it afterwards; never manufacture an idea from a combination of labels.
Personality tendencies are invitations, not medium restrictions. Recent counts and moves are environmental information, never quotas. Runs of similar work and recurring obsessions are allowed.
The technical form selects the existing toolchain. creative_form describes the artistic structure (for example, test-questionnaire or catalogue). Choose member_move from this member's supplied vocabulary. Describe source_domain, sensory_mode, dimensionality, temporal_mode, agency and randomness using the schema vocabularies.
Notice material life as well as software: physical objects, language, printed matter, buildings, measurement, social procedures, sound, transport, domestic objects, nature, signage and mathematics. The recent source-domain report exposes habits without prohibiting another interface work.
Weekly words remain optional and independent of these descriptive statistics.
